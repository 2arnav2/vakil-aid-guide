Landing

ENTRY

Screen

Existing landing page, re-themed to the reference palette. Gold wordmark, cyan glow, single primary action.

  • Reset any stale case state

01

Legal Interview — case intake

INTERVIEW

Screen

  • Top bar: brand, Case Analysis, STAGE: INTERVIEW
  • Left: Legal Interview + empty state + composer
  • Right: Findings skeleton, empty terms

User action

Types or speaks the case. Presses send.

System

  • Validate ≥ 3 characters
  • Reset context, messages, cards
  • Call analyzeCaseSmart()
  • Show user bubble + typing
“Describe your legal situation. Include what happened, who was involved, and any action already taken.”
Exit → first clarifying question or summary
02

Clarification loop

INTERVIEW

Question order

  • Have you filed a police complaint (FIR)?
  • Were there witnesses?
  • Any photos, CCTV, medical records?
  • Was the vehicle insured?
  • Was anyone injured?
  • Hit-and-run, drunk, licence, speed…

User action

Chip, typed answer, voice, or Skip — show best answer.

Timestamps and avatars match the reference.

System

  • Store answer in context
  • Re-run engine
  • Ask next or advance
  • Populate extracted terms live
“Were there witnesses who saw what happened? Can you provide their contact details or descriptions?”
Exit → no questions left / skip / enough facts
03

Summary review

SUMMARY

Screen

  • Left: collected-summary message
  • Right: Summary card
  • Stage: SUMMARY

User action

Confirm analysis or Edit details.

System

  • Confirm → finalize result
  • Edit → focus composer, stay in SUMMARY
  • Keep animation untouched
“Perfect! I've gathered the necessary information. Here's a structured summary of your case. Please review it carefully — if anything needs adjustment, let me know before we finalize the legal analysis.”

Offline rules + honest uncertainty note
